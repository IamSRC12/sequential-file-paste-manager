## Overview

Sequential clipboard manager with multi-slot FIFO/LIFO paste buffers and history tracking.

## ✨ Features

- Multi-slot FIFO / LIFO paste buffers
- Clipboard history tracking
- Sequential file pasting
- Desktop and web tooling
